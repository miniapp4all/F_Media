## 📌 Overview / Tổng quan

**EN:** **F_Media** is a powerful, lightweight standalone media player powered by the robust **MPV engine**. Designed for ultimate playback performance, seamlessly supporting dual-monitor setups, real-time VR conversion, intuitive library organization, and modular controls.

**VI:** **F_Media** là trình phát media độc lập, mượt mà và mạnh mẽ dựa trên **nhân MPV** đỉnh cao. Ứng dụng được tối ưu toàn diện cho trải nghiệm phát media cao cấp: tự động xuất màn hình thứ 2, biến mọi video thành chuẩn VR SBS, quản lý thư viện trực quan và giao diện linh hoạt.

## ✨ Key Features / Tính năng nổi bật

* 🎬 **Powerful MPV Engine / Nhân MPV mạnh mẽ:** Effortlessly plays all video and audio formats with maximum quality and low CPU/RAM usage. *(Phát mượt mà mọi định dạng video & audio nhờ nhân MPV tối ưu).*
* 🖥️ **Auto Dual-Monitor Playback / Phát độc lập màn hình thứ 2:** Automatically detects and controls playback on a second screen independently. *(Tự động phát và điều khiển độc lập trên màn hình thứ 2).*
* 🥽 **Universal VR SBS Mode / Chế độ VR SBS mọi Video:** On-the-fly Side-By-Side VR conversion for *any* video. *(Chuyển đổi mọi video thường sang dạng VR Side-By-Side lập tức).*
* 📁 **Visual Folder Library / Quản lý thư viện trực quan:** Organize and browse your media collections directly by clean folder structures. *(Quản lý thư viện media trực quan, thông minh theo cấu trúc thư mục).*
* ⚡ **Real-Time Smooth Timeline / Timeline mượt nhẹ độc quyền:** Exclusive timeline rendering for precise, instantaneous seeking without lag. *(Thanh timeline độc quyền, cuộn/tua mượt mà theo thời gian thực).*
* 🎛️ **Detachable Control Panel / Thanh điều khiển tách rời:** Completely detach and position the control panel anywhere on your screen. *(Thanh điều khiển linh hoạt, hoàn toàn có thể tách rời).*
* 🖱️ **System Integration / Tích hợp Windows Context Menu:** Supports right-click "Open with" integration as a full standalone media player. *(Gắn chuột phải "Open with" tiện lợi như ứng dụng media mặc định).*
